Installing query-cache-protobuf
==================

Installing `query-cache-protobuf` from the main channel can be achieved by:

```
conda install query-cache-protobuf
```

It is possible to list all of the versions of `query-cache-protobuf` available on your platform with `conda`:

```
conda search query-cache-protobuf
```
